# zeitheist-26

Official Web Experience for **ZEITGEIST'26** — The flagship annual cultural festival of IIT Ropar.

## 🩸 Features
- **Atmospheric Gothic & Horror Theme:** Immersive 3D interactive hero with Occult Sigil, symmetric Jack-o'-Lanterns with interactive flames, and cemetery ground mist.
- **Cinematic Procedural Storm Engine:** High-voltage branched lightning strikes every few seconds, wind-swept driving rain, and startled bats scattering into the dark sky.
- **Custom Interactive Cursors:** Sleek tracking ring and red ember dot.
- **Full Multi-Page Suite:**
  - `about.html`: Lore dossier and festival archive
  - `events.html`: 60+ classified competitive arenas
  - `pronites.html`: Headline midnight concerts and star acts
  - `schedule.html`: 3-day timeline
  - `passes.html`: Entry tiers and clearance passes
  - `sponsors.html`: Partners and benefactors
  - `team.html`: Organizing council
  - `gallery.html`: Polaroids and archival footage
  - `contact.html`: Sector command and transit guides

## 🚀 Running Locally
```bash
python -m http.server 8000
```
Open `http://localhost:8000` in your browser.
